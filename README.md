# Figuras Geométricas — Calculadora de Perímetros

**Estudiante:** Álvaro Muñoz  
**Asignatura:** Programación Híbrida  
**Institución:** Iplacex

## Descripción

Este proyecto consiste en una aplicación web desarrollada con Ionic, Angular y TypeScript que permite calcular el perímetro de un círculo y un triángulo escaleno.

La aplicación permite seleccionar una figura, ingresar sus medidas y visualizar el resultado. También incluye validaciones para evitar cálculos con medidas incorrectas.

## Tecnologías utilizadas

- Ionic Framework
- Angular
- TypeScript
- HTML y SCSS
- Node.js y npm

## Funcionalidades

- Selección de la figura geométrica.
- Cálculo del perímetro de un círculo.
- Cálculo del perímetro de un triángulo escaleno.
- Validación de las medidas ingresadas.
- Visualización de diagramas y resultados.

## Instalación y ejecución

1. Instalar Node.js y npm.
2. Descargar o clonar este repositorio.
3. Abrir una terminal en la carpeta del proyecto.
4. Instalar las dependencias:

   `npm install`

5. Iniciar el servidor de desarrollo:

   `npx ng serve --host localhost --port 8100`

6. Abrir `http://localhost:8100` en el navegador.

## Estructura del proyecto

- `src/app/home/`: página principal.
- `src/app/components/`: componentes de círculo y triángulo.
- `src/app/models/`: clases y cálculos geométricos.
- `src/assets/images/`: diagramas SVG.
